# Go-LLM

## What this library is

A Golang library to create AI Agents. Starting from simple LLM interactions such as tool calling up to LLM chaining.

## V1 Core Capabilities

1. SOTA Provider Support
   a. Anthropic
   b. OpenAI

2. Tool Calling
   a. Custom Tool Creation
   b. Built-In Skill Tool

3. Conversation Persistence
   a. SQL

4. Context Management
   a. Appending or Deleting Messages

5. LLM Chaining
   a. Sequential LLM Calls with Context Sharing

## Explicitly Out of Scope

- UI Interfaces (Web Applications or CLI Applications)
- Native HTTP or API layer
- Support for ALL SOTA Model Providers
